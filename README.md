# Chiaki-lang
어떻게 언어 이름이 키보토스 기자 GOATㅋㅋㅋㅋㅋㅋㅋㅋㅋ

**치아키어(ChiakiLang)** 는 넥슨게임즈의 게임 《블루 아카이브》에 등장하는 모토미야 치아키에서 영감을 받아 제작한 난해한 프로그래밍 언어(Esolang)입니다.

치아키어는 한글 명령어와 `;`, `:` 등의 기호를 활용하여 계산, 입출력 및 프로그램의 흐름을 제어할 수 있도록 설계되었습니다.

치아키 ㅈㄴ 예쁘면 개추 수영복 까리하게 나옴

## 특징

- 한글을 이용한 명령어
- 세미콜론으로 정수를 표현하는 독특한 수 체계
- 사칙연산 중 덧셈, 뺄셈, 곱셈 및 거듭제곱 지원
- `모`, `토`, `미`, `야`를 조합하는 변수명
- 정수 및 유니코드 문자 출력
- 조건문과 GOTO를 통한 흐름 제어
- 임의 정밀도 정수 지원
- 한 줄에 하나의 명령어를 작성하는 구조

## 기본 문법

### 숫자

| 코드 | 값 |
|---|---|
| `;` | 1 |
| `;;` | 2 |
| `;;;` | 3 |
| `:` | 0 |
| `:;` | -1 |

### 명령어

| 명령어 | 기능 |
|---|---|
| `현장보도입니다!` | 정수 출력 |
| `와~ 대단하네요!` | 유니코드 문자 출력 |
| `탐사보도입니다!` | 정수 입력 |
| `전방에 특종 발견!` | 변수 대입 |
| `네? 황송합니다!` | 변수 참조 |
| `그게 정말 사실인가요?` | 조건문 |
| `자 여기 보세요!` | 지정한 줄로 이동 |
| `음, 만족스러운 취재였어요!` | 프로그램 종료 |

## 예제

### Hello, ChiakiLang!

다음 프로그램은 정수 3과 5를 출력합니다.

```text
현장보도입니다!;;;
현장보도입니다!;;;;;
음, 만족스러운 취재였어요!
```

예상 출력:

```text
3
5
```

### 문자 출력

다음 프로그램은 `Hi`를 출력합니다.

```text
와~ 대단하네요!;;;;;;;;;키;;;;;;;;
와~ 대단하네요!;;;;;;;;;;^;;치;;;;;
음, 만족스러운 취재였어요!
```

첫 번째 문자 `H`의 유니코드 값은 72이고, 두 번째 문자 `i`의 값은 105입니다.

각 문자는 정수 계산 결과를 유니코드 문자로 해석하여 출력합니다.
